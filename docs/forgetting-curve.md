# 忘却対策の具体設計（決定済）

`Design.md` §8 #2 の詰め作業の成果。[`quiz-cadence.md`](quiz-cadence.md) の「習熟で軽量化」モデルと対をなす、再クイズ間隔モデルを定義する。

## 参照する設計原則

- `Design.md` §1: 1回10-15分、気が向いたとき1回起動（プレイ間隔は不規則）
- `Design.md` §8 #1: 「忘却曲線に合わせる」緩和案

## 決定: 一律「N戦闘後にフル操作復活」（最小実装版）

1ラン内で全カード共通のルール。

**仕様:**
- 各カードは状態として「最後にフル操作した戦闘番号」を持つ
- 現在の戦闘番号 - 最後にフル操作した戦闘番号 ≧ N の場合、次回使用時はフル操作復活
- それ未満なら短縮版／自動発動
- N の暫定値: 3戦闘（試作で調整）

**理由:**
- 最小実装で「習熟軽量化」の基本体験を試作・検証できる
- N のチューニングは試作で1日でできる。SRS 系は理論優先で実機検証が後ろ倒しになりがち
- 後述の将来拡張は、本モデルの状態管理を前提として再利用可能

**却下案（将来の拡張オプションとしては道を残す）:**
- カード別 SRS ライト（Anki 風、正解回数で間隔が伸びる）: 未試作段階で導入すると「正しい間隔」のチューニングが難航
- ラン横断・実時間 SRS フル版: §6 図鑑機能と一体化するので範囲が膨らむ

## 範囲外（将来の検討）

- ラン横断の長期記憶測定（§6 図鑑の学習進捗と統合）
- 実時間ベースの SRS（§1「気が向いたとき」との相性は良いが、未試作段階では尚早）

## 試作で検証すべきこと

- N の具体値（3戦闘前提でチューニング、必要なら可変化）
- 「短縮版」と「自動発動」の境界（カードによってどちらを使うか）
- 復活前にカードを使わなかった場合の扱い（戦闘数だけで判定するか、ラン経過時間も加味するか）
