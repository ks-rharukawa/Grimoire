# クイズのさじ加減（決定済 / レビュー反映済）

`Design.md` §8 #1 の詰め作業の成果。基本形・発動タイミング・失敗時挙動・効果コストとの連動を確定する。再クイズの間隔モデルは [`forgetting-curve.md`](forgetting-curve.md) に分離。

> **用語注:** 本ドキュメント内の「クイズ」は、伝統的な Q&A 形式ではなく、`Design.md` §5 の動く図を **使用時理解チェック** として戦闘に統合した「操作型」を指す（決定1 参照）。

## 参照する設計原則

- `Design.md` §4: 理解＝強さ直結、チョコがけブロッコリー回避、効果コストと意味への忠実さの両立
- `Design.md` §5: 動く図の3層構造（対応表・字幕・操作時説明）

## 用語と定義: 理解難度 vs 操作難度

`Design.md` §4「理解＝強さ直結」を保つために、難度を以下の2軸に分離して扱う。混同すると "器用さ＝強さ" に変質して §4 の核が崩れる（codex レビューによる重大指摘の反映）。

| 用語 | 意味 | 例 |
|---|---|---|
| **理解難度** | 概念をどれだけ深く把握しているか / 何が「正しい状態」か分かるかの認知的負荷 | サーキットブレーカーが「連続失敗を一定回数で遮断する」と分かっているか |
| **操作難度** | その「正しい状態」を実現するための操作面の負荷（ステップ数・時間制限・精度） | 粒を遮断する位置にドラッグできるか |

**運用ルール:**
- 効果の強さは **理解難度** に連動させる（§4 の核を維持）
- 操作難度は **二次的・補助的**。アクセシビリティで調整可能（後述）
- **例外: 概念の意味そのものが「タイミング」「精度」にある場合**（例: レースコンディション系）は、操作難度＝理解難度になる。この場合のみ操作精度が強さに連動してよい

## 決定1: 基本形 = 操作型

カードを切ると `Design.md` §5 の動く図がそのまま戦闘画面に出る。プレイヤーが粒の流れを止める／線を引く／ノードに配置する等の操作で「概念の正しい状態」を作り、それが正しい場合に効果発動。

**理由:**
- §4「チョコがけブロッコリー回避」の構造的な正解（学習と遊びを分離させない）
- §5 の3層構造が元から「操作」を前提に設計されている（"操作するたびに、その動きが現実の何に当たるかの説明"）

**未検証コスト:** 全カード分の操作デザインのコスト → 最初の3-5枚で現実性を試作検証する。

**却下案:**
- Q&A 型: 戦闘の流れを止める = チョコがけブロッコリーの典型
- ハイブリッド（弱=Q&A、強=操作）: 最初の試作で2系統作るのは早い

## 決定2: 発動タイミング = 習熟で軽量化

- 初回 → フル操作
- 一度正解 → 次から短縮版／自動発動
- 一定戦闘経過 → 再びフル操作復活（具体は [`forgetting-curve.md`](forgetting-curve.md) 参照）

**理由:**
- §8 本文の提案そのもの（"忘却曲線に合わせる"）
- 習熟感が得られる
- 忘却対策と一体で設計できる

**却下案:**
- 毎回フル操作（テンポ崩壊、習熟感ゼロ）
- 状況依存（ボス戦のみフル等）: 最初の試作で2系統作るのは早い、将来オプション

## 決定3: 失敗時挙動 = シンプル不発（敵によっては暴発自傷）

**基本: シンプル不発**
- 操作失敗 = 効果ゼロ、ターン消費（カードは通常通り捨て山へ送られる。**ラン中の永久喪失ではない**、次のシャッフルでデッキに戻る）
- 戦闘後の振り返り画面で「正しい操作」のヒント表示

**ヒントの表示形式規律（§4 チョコがけブロッコリー回避）:**
- テキストモーダルの長文説明は避ける（読み飛ばされる典型）
- 動く図の **正しい操作シーケンスを再生** する（プレイヤーは見るだけで分かる）
- 解説テキストは字幕レベルのみ（§5 3層構造の "字幕" に準拠）
- スキップ可だが、最低視聴時間（暫定3秒）を設けて無視されないようにする

**例外: 敵側に暴発トリガー属性**
- 特定の敵戦闘では失敗時に意味と連動した暴発自傷が発動（例: サーキットブレーカー失敗 → 回路ショート → 自傷ダメージ）
- 通常戦闘はテンポを守り、特殊戦闘でメリハリ・緊張感を出す
- 失敗時の演出は最初は generic（一律自傷）、シグネチャカードのみテーマ別演出を後付け
- どの敵が暴発トリガーかは敵設計時に決める（範囲外）

**連続失敗時のサポート（将来検討、codex レビュー反映）:**
- 同一カードを連続失敗（暫定3回）したらチュートリアルモードを発動する案
- §1「未知に出会う」原則を保つため、失敗続きで「このカードは使わない」になることを防ぐ
- フェーズ1では未実装、試作後に必要性を判定

**却下案:**
- 同ターン内リトライ可: "正解するまで連打" になり、ローグライクのカード使用リスクが消える。§4 の "理解＝強さ" が "総当たり＝強さ" に変質する

## 決定4: 効果コストの連動 = 理解難度を主、操作難度を補助、使用制限を従

**主軸: 理解難度（concept depth）**
- 強い効果のカード = 概念が複雑・抽象度高い・前提知識を要求する
- 「正しい状態」が一見では分からない、複数の関係性を理解する必要がある等

**補助軸: 操作難度3レバー（意味と連動する場合のみ強さに反映）**
- ステップ数（1ステップ ↔ 複数ステップ）
- 時間制限の有無／長さ（タイミング概念のカードのみ強さ連動、それ以外はアクセシビリティで調整可）
- 精度要求（精度が概念の本質である場合のみ強さ連動）

**従軸: 使用制限（最強帯のみ）**
- Exhaust（使い切り）／1ラン1回 等を切り札カードに付与

**理由（改訂、codex レビュー反映）:**
- §4 の核「**理解**＝強さ直結」を最も素直に表現できる（"器用さ＝強さ" にならない）
- アクセシビリティ問題の根本回避
- 切り札カードの希少性を出せる
- 「概念の意味が精度・タイミングそのもの」のケースには操作難度も強さ連動できる

**却下案:**
- 操作難度を主軸（旧案）: "器用さ＝強さ" にズレ、§4 の核を破壊するリスク
- 操作難度のみ: 切り札感を出しにくい
- 使用制限のみ: §4 の核が薄まり、Slay the Spire 的になる
- 2軸独立で自由組み合わせ: 意味と乖離した設計が許される、複雑

## アクセシビリティ

「操作難度＝理解難度」と取り違えると、反射神経・視覚精度・運動機能の差が学習体験を阻害する。本ゲームは **理解** をチェックするものなので、操作面の負荷は調整可能とする。

**設定可能項目（暫定）:**
- **時間制限**: ON / OFF（OFF 時は無制限。§4 強さ連動の判定は理解難度のみで実施）
- **操作精度**: 標準 / 緩和（許容範囲を広げる）
- **ステップ数**: 変更不可（理解の本質に関わるため）

**注意:**
- 概念の意味そのものが「タイミング」「精度」であるカード（例: レースコンディション系）は時間制限・精度を切れない（その制約を体験することが学習）。これらのカードは「タイミング系」「精度系」タグを付与し、設定で OFF できないことを明示する
- アクセシビリティモードでも、§4「理解＝強さ」の判定（"正しい状態" にできているか）は不変

## 試作で検証すべきこと

- 「正解操作」の許容範囲の数値化（精度要求の段階分け）
- 短縮版／自動発動の具体的な UI 動作
- 敵の暴発トリガー属性の頻度（多すぎると常時案②化、少なすぎると意味薄）
- 操作難度3段階のパラメータ（ステップ数・時間制限・精度の組み合わせ）
- 戦闘後の振り返り画面の構成
- 連続失敗時のチュートリアルモードの発動条件
- ヒント再生の最低視聴時間
- アクセシビリティモードのバランス差（同じ効果でも有利すぎないか）
- どのカードが時間制限・精度を切れるか／切れないかの分類
